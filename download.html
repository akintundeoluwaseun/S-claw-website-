How much memory (RAM) does that computer have?

How do I check my memory?
  • Windows: press Ctrl + Shift + Esc → Performance → Memory. Or Settings → System → About → “Installed RAM”.
  • Mac: Apple menu → About This Mac → “Memory”.
  • Linux: run free -h and look at “Mem total”.
