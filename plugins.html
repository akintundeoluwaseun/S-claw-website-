Plugins

Teach S-CLAW one program properly

S-CLAW can work a window it has never seen — look at the controls, click, type. That is guessing. A plugin replaces the guessing with knowing, for one particular program, written by somebody who actually uses it.

A plugin cannot contain a program

It is text: instructions, shortcuts, and the name of a door S-CLAW already knows how to open. Installing refuses any file that can run — .exe, .ps1, .py, anything — whatever the plugin says about itself. That is a deliberate limit, not an oversight: if a plugin downloaded from a website could run a program, the website becomes a way to put malware on every machine that trusts it.

And while a task is following a plugin you installed, S-CLAW checks each change with you, even if you have turned that off. Your setting is a judgement about your own tasks, not about somebody else’s recipe.

Installing

Three steps

  1. Download the .zip above. Do not unzip it.
  2. In S-CLAW, open Settings → Plugins and click Install a plugin…
  3. Pick the .zip. S-CLAW checks what is inside it, then uses it the next time a task fits. If it refuses, it says exactly which file was the problem.

You also need the program itself — a Blender plugin cannot work without Blender. Each plugin says what it needs.

For developers

Write one for the program you know

If you use a program every day, you know the ten things people actually ask of it and the five ways it goes wrong. That is a plugin.

It is one Markdown file

A folder with PLUGIN.md in it, zipped. Settings at the top between --- lines, plain instructions underneath.

Name the door

A plugin’s first job is not “where to click” — it is whether the program has a scripting way in. Blender takes Python, Word and Excel have COM, Inkscape has a command line. Driving a program through its own script engine is near certain and fast; the mouse is the fallback for programs with no door.

Write down what goes wrong

“A new Blender scene already holds a cube, a camera and a light” saves more failures than three more steps.

Fill in prompts

The things a person would really say. They are shown to people, and S-CLAW matches on them — you know the words your users type, and a description written for a reader rarely contains them.

Read the format Submit a plugin

There is no upload form here yet: plugins are reviewed by hand before they are listed, because anyone installing one is trusting it with their computer. Open an issue with a link to your .zip and it gets read.
